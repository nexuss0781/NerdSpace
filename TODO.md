# Nerd Space — build outcomes

## 1. Project switching and the left workspace sidebar
- [x] Create and open coding projects in the workspace.
- [x] Use a far-left, scrollable project sidebar that is slightly wider than VS Code’s Extensions rail and leaves room for project icons.
- [x] Collapse the project sidebar from its top-left control into a scrollable initials-only view showing each project’s first letter, then expand it back to named project entries.
- [x] Browse the active project through a VS Code-like Explorer panel on the left and edit files in the central workspace.
- [x] Keep the workspace visually close to the supplied Visual Studio Code layout reference; keep the experience clean, simple, animated, and free of jargon-heavy text.

## 2. File and folder tree management
- [x] Support full file and folder CRUD in the project tree: create, rename, move, and delete files and folders.
- [x] Open files from the tree and switch among open files in editor tabs.

## 3. Monaco editing and save state
- [x] Use Monaco Editor for the editor and its default autocomplete suggestions.
- [x] Support syntax-aware editing for any programming language available through Monaco.
- [x] Track unsaved changes and save edits.
- [x] Provide a fully integrated development environment with no terminal and no AI workspace or AI space.

## 4. Alphabet-only symbol sequences
- [x] Provide alphabet-only short sequences as substitutes for programming symbols that are normally typed from keyboard characters; the engine translates the sequences into the actual characters and saves them as those actual characters.
- [x] Give programming characters available on the keyboard alphabetic short-sequence equivalents, and make the sequence entry understandable through a visual mapping.

## 5. Clear, visual interactions
- [x] Keep navigation and file actions visual and simple, with restrained animations and no text jargon.

> Project names and file contents are stored in browser storage on this device; this version does not connect to the device’s native filesystem.
